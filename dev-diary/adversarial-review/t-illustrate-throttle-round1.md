## Items probed and found sound (not findings)

- **Retry classification.** Only `ErrRateLimited` and `ErrTransient` are waited on. `ErrBadRequest`, `ErrUnauthorized`, `ErrPaymentRequired`, `ErrModelNotFound` and an unclassified error surface on attempt 1, each asserted with `errors.Is` in `TestRetryThrottled` and `TestIllustrate_NonThrottleErrorsAreNotRetried`. The classification matches `gmi/errors.go` ("caller MAY retry again" on `ErrTransient`; "back off and retry with the same request" on `ErrRateLimited`). The concern with `ErrTransient` is count and cost (M4), not membership.
- **`retryAfter` parsing** otherwise: absent body, no `rate_limit`, malformed JSON, zero and negative values, non-429 sentinels and trailing text all fall back to the backoff without panicking; a float or string value fails `Decode` and falls back. Reads one numeric field, never the message wording (AGENTS §Errors satisfied). Only overflow (M1) is missed.
- **Unbounded sleep:** every wait is capped at `MaxThrottleBackoff` (provider value, backoff and spread all inside the `min`), and the backoff doubling is capped, so no single sleep is unbounded.
- **Deadlock:** `refLimit = min(refLimit, limit)` is at least 1; the errgroup fan-out is unchanged and each task has a single exit (retry loop bounded by `Attempts`, sleep cancelled by ctx). No lock is held across a sleep. No nested errgroup, so the reference limit cannot starve the page phase.
- **Races:** `go test -race -count=15` clean; `rand/v2` top-level functions are goroutine-safe; `defaultSleep` is read in `resolve` before any goroutine starts.
- **Sentinels survive:** the exhaustion annotation wraps with `%w`; `GMISentinelsSurvive`-style tests stay green.
- **Interaction with the media client:** the new layer sits above the client's own single resubmit, so `ErrTransient` is counted per outer attempt; the doc says so correctly.
- **Out-of-seam observation (not counted):** `internal/audio/audio.go:99` still says the media client's retry "is the only retry — this package adds no second layer", which `internal/audio/throttle.go` already contradicts. Pre-existing and not in this diff; the orchestrator should route it, not this track.

## Verdict

**REMEDIATE — 0 C / 1 H / 4 M / 3 L.** The 429 handling for reference sheets works and is well tested on the wire, but the fix leaves the page phase able to fail the same way (H1, simulated at a 94 % failure rate in the realistic window state), a garbled `retry_after_ms` can disable the backoff (M1), cancellation is mis-reported as failure (M2), the real clock is untested (M3), and the transient path inherits a rate-limit-sized retry budget with no overall bound (M4). Every finding needs a row in `t-illustrate-throttle-remediation-round1.md` and a fresh round-2 reviewer. No exemption applies: none of the L rows is arguable-free prose-only (L2(b) changes a string asserted by behaviour, L1 and L3 add tests and a PLAN entry).
