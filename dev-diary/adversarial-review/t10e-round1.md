## Summary of the diff and deliverables

Track T10e provides the live verification that T10c previously lacked (where all stages had been verified against unit fakes). It validates the full Phase-B generation pipeline end-to-end:

1. **`internal/bookgen/live_test.go`**:
   - Gated with `//go:build live` at the top of the file. Completely decoupled from CI and standard `go test ./...` suites.
   - Comprehensive graceful skipping: calls `t.Skip` if `GMI_API_KEY` is unset or if system binaries `ffmpeg` or `ffprobe` are missing from `PATH`.
   - Mounts complete pipeline with SQLite `store`, `mediastore`, `stream.Broker`, and `job.Runner`.
   - Exercises real HTTP routes via `Handler.ServeHTTP` (`POST /interviews/{id}/generate` and SSE `GET /interviews/{id}/generate/events`).
   - Supports live GMI Cloud calls with retry/exponential backoff for rate limits/transients, and incorporates local disk caching per operator directive to avoid credit burn during test cycles.
   - Verifies the full Stage 1 (M3 structure) -> Stage 2 (Illustrate & Judge) -> Stage 3 (Narrate) -> Stage 4 (ffmpeg 7.1 video render) -> Stage 5 (mediastore MP4 persist) pipeline.
   - Verifies SSE event sequence on `book:{id}` topic: exactly 8 `page_approved` events in order, 1 `book_ready` event, and 0 `failed` events.
   - Verifies cold HTTP serving via `GET /media/{id}`:
     - 8 page illustrations served with `200 OK` and `image/jpeg`.
     - Full video GET served with `200 OK`, `video/mp4`, `Cache-Control: public, max-age=31536000, immutable`, and quoted `ETag`.
     - Range GET served with `206 Partial Content`, `Content-Range: bytes 0-1023/{total}`, and byte-for-byte slice equality.
   - Validates the resulting MP4 video (`data/live/t10e-book.mp4`) via `ffprobe`, asserting h264 video, aac audio, and 1080x1350 (4:5 portrait) dimensions.

2. **`dev-diary/adversarial-review/t10e-live-record.md`**:
   - Documents the full live API run (`task-399.log`), recording exact timestamps and response shapes for M3 transcript structuring (22.4s) and `seedream-5.0-lite` illustrations.
   - Records live M3 multimodal consistency judge decisions, including real character drift detection on Page 4 (hair color/collar) and Page 8 (raincoat changed to pajamas) with automatic T7 regeneration closing loop triggering and subsequent approval on re-render.
   - Documents the upstream GMI Cloud MiniMax TTS cluster capacity exhaustion (`503 "Upstream capacity temporarily exhausted"`), confirming clean pipeline failure and exact-once SSE `failed` event publication.
   - Documents the subsequent full end-to-end cached video assembly and serving verification run.

3. **`data/live/t10e-book.mp4`**:
   - Real, playable 42.52s book film generated by ffmpeg 7.1 and verified via `ffprobe`.
