## Notes for round 3

- Registry semantics worth probing: the first creator's clock wins for a registry entry (harmless in production, where everyone uses the real clock; documented on `get`). A caller that sets only `Sleep` or only `Now` gets a private pacer; production sets neither.
- The pacer still spends a slot for a cancelled queued waiter, so a cancelled book leaves its reserved slots in the shared queue and the next book is spaced slightly late; that errs sparse and is what `TestIllustrate_RePostAfterAFailedRunQueuesBehindIt` relies on.
