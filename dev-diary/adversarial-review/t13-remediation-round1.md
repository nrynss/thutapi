# T13 remediation round 1

| Finding | Fix | Verification |
|---|---|---|
| H1 | `VoiceSampleConfig.PublicOrigin` is required and validated as an absolute HTTPS origin. The upload response is the typed `VoiceSampleResponse` with absolute `media_url` and `source_audio`; `NewVoiceCloneRequest` validates the confirmed clone request input fields and keeps the provider response/voice-id handoff raw for the consented live probe. The adult UI keeps the returned source URL as the selected clone input and explicitly says the library narrator remains selected until that probe. `PUBLIC_ORIGIN` flows from `cmd/thutapi` configuration into the handler; startup fails when it is absent or invalid. | `TestVoiceSampleHandler_DefaultsTranscodeAndPersist`, `TestNewVoiceCloneRequest_RequiresAbsoluteHTTPSSource`, and origin validation cases pin the absolute URL and typed request boundary. No live clone call or fabricated response shape is claimed. |
| H2 | Added an ffmpeg duration probe and reject source media over `MaxVoiceSampleDuration` (15 seconds) before transcoding. Removed ffmpeg `-fs`, which can report success after clipping; the completed output is now stat-checked against `MaxTranscodedVoiceBytes`. The input byte cap remains enforced before ffmpeg. | `TestVoiceSampleHandler_LongPreparedFileRejectedBeforeTranscode` rejects a compressed over-duration input before `Run`; `TestVoiceSampleHandler_FilesizeFlagMutationCannotSilentlyClip` makes a `-fs` mutant fail; existing output-cap and input-cap cases remain green. `TestParseFFmpegDuration` pins the probe parser. |
| H3 | Added affirmative server enforcement through `X-Voice-Sample-Consent: yes` and an adult checkbox that gates both capture controls. Copy discloses the app's public media URL, GMI fetch, provider-hosted public generated audio, and that retention is not session-only. The route's media remains unplaced so the T11 retention sweep contract applies; this record deliberately records that dependency rather than promising deletion that does not yet exist. | `TestVoiceSampleHandler_ConsentRequired` pins refusal before persistence; `static/browser-test.js` pins consent default-off and controls disabled until acknowledgement. The UI copy names the unplaced-sample retention sweep and does not claim session-only storage. |
| M1 | Browser recording now chooses the first supported `audio/webm;codecs=opus`, `audio/webm`, `audio/mp4;codecs=mp4a.40.2`, or `audio/mp4` candidate with `MediaRecorder.isTypeSupported`. If no candidate or recorder is available, it stops tracks and gives the adult the prepared-file fallback. | `node --check static/app.js` and the browser harness `testRecorderMimeNegotiation` pin a supported MIME selection and consent header; the candidate list and `isTypeSupported` call are pinned in the shipped browser code. |
| M2 | The handler's default executable is now `/usr/local/bin/ffmpeg`; an explicit `VoiceSampleConfig.FFmpegPath` still overrides it. | `TestVoiceSampleHandler_DefaultsTranscodeAndPersist` pins the production path and the existing helper exercises the override path. |

The T11 retention contract for this route is: every successful T13 sample is an
unplaced `audio/mpeg` media row, and T11's unplaced-orphan sweep must delete its
row and blob under the app's configured retention policy. Until that sweep is
landed, the UI says the sample is not session-only. No real voice sample or
clone call was made during this remediation.
